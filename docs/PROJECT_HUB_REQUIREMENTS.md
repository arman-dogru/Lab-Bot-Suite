# Project Hub acceptance requirements

Build and deploy Project Hub, a useful personal project manager, in /workspace/project-hub. Choose sensible defaults and finish without further prompting.
Features: projects with archive/reopen; a Kanban task board (To do/Doing/Done, priority and due dates); Markdown notes with revision history; document uploads/downloads; search; project exports as JSON and Markdown. Make the interface polished, responsive and keyboard usable, with clear empty/error states and no infrastructure clutter. Seed an idempotent Jetson Lab demo with realistic tasks and notes.
Add a local automation webhook to create tasks. Protect it with an app-only bearer secret in a private file; never print secrets in chat or logs. No Grok/Discord credentials in the app.
Install a lightweight ARM64-compatible stack in persistent environments and record exact dependencies. Deploy as an independent non-root service named jetson-project-hub, using the tested official Hermes base image if a modern container is needed. Publish ONLY host 127.0.0.1:8787. Persist SQLite and uploads under the project. Use jetson-host SSH for host administration. Preserve the OS/drivers and all existing bot, budget and approval controls.
Verify real project/task/note CRUD, note revisions, upload/download bytes, search, exports, invalid inputs, webhook authentication, and persistence after restarting the app. Guard upload paths, request sizes, and state-changing requests. Keep test data disposable and isolated.
Write README operating, snapshot/restore and deployment commands. Save milestones in PROGRESS.md and inspect existing results after interruptions. Return a concise final URL, source path, verified checks and actual exit status. Continue via the existing goal mechanism until deployed and tested; keep routine work out of chat.

Long-task execution: continue the existing app.py scaffold and PROGRESS.md. Work in small files or bounded patches; keep each source inspection or command output under 3,000 characters. Do not dump the complete application into tool output. Save each verified milestone before continuing. Never discard already completed work because a conversation was reset.
